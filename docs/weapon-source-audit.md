# Оружие — сверка с установленной Tyranny, 11 октября 2026

`scripts/audit_weapon_source.py` независимо читает установленную игру:
архивы items/DLC и resources.assets/QualityScalingWeapons. Проверены все
302 оружейных предмета каталога (щиты без атаки не включены в это число).
`catalog/weapon_source.json` хранит снимок исходных атак, включая внешние
ссылки на атаки дротиков, для запуска сайта без установленной игры.

Исправления:

- Восстановление ошибочно читалось из несуществующего RecoveryTime.
  Используется PersonalCooldownModifier с учётом таблицы качества.
- Отдельные melee-колонки качества метаемых кинжалов не смешиваются с
  характеристиками броска. Кинжалы остаются оружием ближнего боя;
  дротики используют исходную дистанционную атаку (8 м).
- Сохраняются дробные границы исходного урона, точность, пробивание,
  основной/альтернативный тип, защита цели, дальность, прерывание,
  категория скорости, множитель и флаги исходной атаки.
- В карточках магазина, каталога и инвентаря видны нулевые показатели.
  API отдаёт единый weaponStats; при экипировке бой использует те же
  дальность, защиту и типы урона, а не общие значения для категории.
- BestOfType выбирает тип против наименьшего текущего поглощения цели.
  Случайный тип выбирается при атаке; предпросмотр учитывает все варианты.

Адаптация остаётся пошаговой: 1 клетка = 1 м; дробная дальность округляется
вверх до клетки (0,5 м → 1 клетка). Восстановление оружия — добавка, не
полное время персонажа: 1 раунд = 10 сек. Урон для броска округляется
до целого; исходные дробные значения остаются в gameData. Категория
скорости показывается отдельно; она не вводит дополнительное ожидание
в реальном времени. ДПС из оригинального боя не подменяется выдуманным.

Вес не является системой перегрузки: не суммируется и не влияет на
передвижение. Старое поле участвует только в освобождении мелких предметов
(0 < weight ≤ 0,25) от места в сумке. Это не подтверждённая масса из игры.

Проверки: независимая сверка с установленными архивами — 302 предмета,
0 расхождений; 84 теста торговли/экипировки/боёв/локализации, включая
миграцию нумерованных вариантов без потери инвентаря. Сложные условные
эффекты предметов не объявляются полностью автоматическими: прежние
ограничения и предупреждения остаются видимыми в каталоге.
