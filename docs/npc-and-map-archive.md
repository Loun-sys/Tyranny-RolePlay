# Архив НПС и свободное размещение токенов

В мастерской появилась кнопка «НПС»: личные токены и неизменяемые исходные шаблоны игры. Шаблон копируется в личный архив, затем его параметры можно менять. Публикация показывает запись в разделе «НПС» общего архива; личные заметки не выдаются публичным API. Данные привязаны к мастеру и Discord-серверу.

Редактор карт не требует четырёх фиксированных стартов. Выберите «Поставить токен», НПС или персонажа игрока из списка, затем клетку. Один игрок имеет одну стартовую позицию; один шаблон НПС можно разместить несколько раз. НПС может быть противником, союзником или нейтральным. Ластик удаляет размещение, не саму запись. Пустые карты сохраняются. Для запуска персональной тренировки на карте мастер должен разместить этого игрока. Другие игроки в тренировке отображаются как союзные токены, но не управляются отдельными сетевыми сессиями.

Старые карты читаются для совместимости, при редактировании фиксированные спавны убираются. Встроенная тренировка с манекенами остаётся отдельным режимом.

`catalog/game_npcs.json` содержит 1023 записи с боевыми параметрами из всех 224 установленных Unity-архивов, включая дополнение. Противники и нейтральные НПС, спутники и служебные записи выделены в категории. Дубли имён с разными ID сохранены. `catalog/game_npc_audit.json` перечисляет проверенные архивы. Это исходные параметры префабов, а не итоговые параметры всех сцен: масштабирование уровнем, сложностью и сценарием не воспроизводится. Безымянные объекты имеют исходный идентификатор для поиска. Портрет можно задать вручную.

Базовое перемещение — 5 клеток (5 метров). Особые эффекты переведены по правилу: `ceil(секунды / 10)` раундов. Реализованы распознаваемые временные модификаторы, контроль против атак по возможности, щиты, поглощение здоровья, очистка бонусов и отложенный урон. Условные эффекты предметов, цепочки рикошетов, усиление известностью и некоторые особые способности ещё не реализованы полностью; интерфейс предупреждает об этом. Смена сторон/полноценный ход ИИ — не часть тренировочного режима.

Проверки: `python -m unittest test_npcs test_campaign test_smoke`, `node scripts/test_campaign_ui.cjs`.
