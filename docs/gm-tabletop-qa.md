# Стол мастера

Карта занимает рабочую область мастерской. Справа остаётся компактная очередь, которую можно свернуть до текущего хода. Кнопка «Панель» открывает карточку, список участников или архив НПС поверх карты, не уменьшая её масштаб. При открытии карточки очередь сначала сворачивается; её можно снова развернуть.

- Токен: нажать для выбора, потянуть на свободную клетку для перемещения, ПКМ для быстрых правок. Двойное нажатие открывает полную карточку. Стрелки передвигают выбранный токен по одной клетке.
- ХП у токена: `-10` — урон, `+10` — лечение, `=80` или `80` — точное значение. Enter сохраняет. Урон/лечение ограничены 0–максимумом; недопустимое точное значение отвергает сервер.
- «Воздействия» у токена: эффект, сила и число раундов. Крестик снимает эффект. Число активных эффектов отображается на токене.
- Колесо масштабирует вокруг указателя. ПКМ + движение, средняя кнопка или пробел + движение сдвигают поле. На телефоне используется инструмент «Поле»; токены поддерживают перетаскивание пальцем.
- `R` — линейка, `P` — сдвиг поля, `H` — ХП, `F` — фокус, `C` — текущий токен, `0` — вместить, Esc — отмена. Ctrl + перетаскивание также измеряет. Дальность — шахматная, как в TacticalGrid: диагональная клетка равна метру. Измерение никогда не сохраняет движение.
- НПС можно перетащить из архива панели на клетку; повторная расстановка нажатием сохранена.
- Очередь: перетаскивание строк или стрелки меняют порядок, не сбрасывая текущий ход. «Ходить за …» открывает обычный HUD текущего НПС; на ходе игрока доступно наблюдение. Возврат в редактор ждёт завершения действия и подтверждённой остановки HUD.
- `↶` / Ctrl + Z отменяет последнее перемещение только пока ревизия боя не изменилась. Если после движения кто-то совершил действие или внесена другая правка, отмена недоступна. Это не откат всей сцены.

Масштаб и положение поля сохраняются при обновлении состояния и переключении между сценами внутри открытой мастерской. Рюкзаки, награды, боевые правила и данные настоящих сцен не меняются при локальной UI-проверке.
