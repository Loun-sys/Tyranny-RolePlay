# Скрытность, спринт и читаемость токена

Спринт, защита и скрытность применяются одним нажатием: без дополнительного клика на собственной клетке. Спринт тратит действие, даёт +5 м, не может использоваться дважды за ход. Старый приём подготовки атаки удалён из сервера, UI и допустимых назначений быстрых ячеек.

Причина бледного портрета: CSS затемнял всю отключённую кнопку клетки (opacity .48), включая вложенный токен. Теперь отключённые клетки имеют opacity 1. Другие недоступные кнопки сохраняют затемнение. Собственный скрытый токен тоже непрозрачный: небольшая отметка и рамка, без мигания.

Порог поиска 100, обнаружения 200. Базовая скорость подозрения 20/с; спад 15/с после .75 с без наблюдения. Типы восприятия: сверхъестественное 9 м ×1.75; острое 6 м ×1.25; обычное 5 м ×1; слабое 3 м ×.5; невнимательное 1 м ×.1. Нормальная сложность: восприятие `(20 + уровень ×4) × тип`.

Множитель обнаружения: `r = clamp(Хитроумие / восприятие, .1, 3)`; если r<1, 2−r, иначе 1/r. Множитель расстояния 2−1.5×fraction; fraction=(дистанция−1)/max(1, радиус−1). Передний просмотр ничего не бросает и не изменяет подозрение.

## Намеренная настольная адаптация

В оригинале нельзя включить скрытность внутри боя. Здесь это основное действие, поскольку пользователь запросил боевую кнопку. Отключено оригинальное принудительное combat-distance=1: иначе дальность никогда не помогала бы. Контакт на соседней клетке обнаруживает сразу при наличии обзора. Преграды обзора работают; непроходимая клетка сама по себе обзор не закрывает.

Оригинальная ходьба вместо бега адаптирована стоимостью 2 м за клетку (обычная — 1 м). Один раунд = 10 секунд. Движение расходует часть этого времени (2 с на единицу движения), конец раунда — остаток, не дополнительные 10 секунд. Проверяются все клетки маршрута, а не только конечная. Хитроумие включает экипировку и действующие модификаторы.

У каждого врага своя память подозрения. При 200 хотя бы у одного врага персонаж раскрыт. Манекены и союзники не обнаруживают. Атаки, активные способности, заклинания, применение предмета и спринт прекращают скрытность; неудавшееся действие откатывается. Прямую цель нельзя выбрать на сервере, скрытый персонаж не провоцирует атаки по возможности, пока не обнаружен. Области могут задеть скрытого персонажа. Владелец, союзники и мастер всегда видят его; для мастера не вводится туман войны.
